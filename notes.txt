** DEPLOYED CODE WAS
    app.use(
    cors({
        origin: process.env.FRONTEND_URL || "http://localhost:5500",
        credentials: true,
    })
    );

** ON RENDER, ENVIRONMENT VARIABLE IS 
    FRONTEND_URL=https://to-do-gvbq.onrender.com,http://localhost:5500

This is one long string, so express sees this header as
Access-Control-Allow-Origin:
https://to-do-gvbq.onrender.com,http://localhost:5500

Browser says:
   1. I asked for ONE origin.
    2. You gave me TWO.
    3. Request blocked.

CORS allows only one origin per response.
